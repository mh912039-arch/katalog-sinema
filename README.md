# Katalog Sinema

Buka index.html di browser. Seluruh HTML, CSS, JavaScript, gambar, dan video berada dalam satu folder. Tidak perlu npm atau proses build. Untuk GitHub Pages, letakkan isi folder ini pada direktori publik repositori.

## Pembaruan
- Home dengan hero, pilihan film, serta tautan katalog dan kontak.
- Profil website dan pengelola.
- Kontak dengan email dan tautan pencarian alamat Google Maps.
- Formulir nama, email, subjek, dan pesan dengan validasi browser.
- Desain responsif, navigasi aktif, label formulir, dan fokus keyboard.

## Alamat
